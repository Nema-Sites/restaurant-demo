# 🍽️ Restaurant Demo — Ordering & Reservations Template

A complete restaurant website demo covering the three things a restaurant site actually needs to do: tell the story, take online orders, and book tables. Built as a **white-label template** — branding, menu, hours, and copy are all placeholder-driven so it can be reskinned for a real restaurant in minutes.

🔗 **Live demo:** [restaurantdemo.nemasites.com](https://restaurantdemo.nemasites.com)

## ✨ Highlights

- 🛵 **Online ordering** — a full menu page where guests browse dishes and place an order for delivery or collection
- 📅 **Table reservations** — a booking flow that takes about a minute: date, time, party size, done
- 🏠 **Landing page that sells** — story, stats (seating, rating, local sourcing), featured dishes, hours, and location
- 🎨 **White-label by design** — the live demo intentionally ships with placeholder branding ("Restaurant Name", "Tagline") to show clients exactly which parts get customised
- 📱 **Fully responsive** — mobile-first, since most restaurant traffic is on a phone

## 🧠 Why I Built This

Most small restaurants either have no website or a static page with a PDF menu — while paying commission on every third-party delivery order. This demo shows restaurant owners what owning their own ordering and reservation flow looks like. Keeping the branding as visible placeholders turns the demo into a sales tool: clients can immediately picture their own name, menu, and photos in place.

## 🗺️ Demo Walkthrough

1. **Landing page** → story, key stats, favourites from the kitchen, hours and location
2. **Order Online** → browse the full menu and build an order
3. **Reservations** → book a table for tonight in under a minute

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | Multi-page HTML5 + vanilla JavaScript |
| State | Client-side (cart and booking state in the browser) |
| Styling | Custom CSS, responsive layout |
| Deployment | Self-hosted with Coolify + nginx on a Nemasites VPS |

## 📁 Project Structure

```
restaurant-demo/
├── index.html          # Landing page — story, stats, favourites, hours
├── menu.html           # Online ordering — full menu and cart
├── reservations.html   # Table booking flow
└── assets/             # CSS, JS, images
```
